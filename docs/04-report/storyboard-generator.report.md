# 범용 콘티 도구 — 첫 완성본 보고서

## 완료 범위

구조화 제작 자료를 프로젝트별로 가져와 컷·다중 프레임·오디오·글자·전환·연속성 상태를 편집하고, Codex App에서 컷 제안·이미지·가이드 음성을 생성한 뒤 시간순으로 검토하는 로컬 웹 도구를 완성했다. 프로젝트 JSON, 그림 콘티 PDF, 제작 목록 CSV를 내보낼 수 있다.

특정 작품 값은 `production-v1` 입력 어댑터와 fixture에만 있다. 공통 모델과 UI는 프로젝트 ID, 인물, 장면 수, 모드, 분량을 고정하지 않으며 `native-v1` 입력으로 구조와 길이가 다른 프로젝트를 코드 변경 없이 처리한다.

| 실제 제작 사례 | PRJ-007 `SEG-008` 5컷 제안, 프레임 재생성·승인, 5,600ms 음성 반영 |

세부 대응표와 남은 검토는 [구현 일치 분석](../03-analysis/storyboard-generator.analysis.md)을 따른다.

## 운영 방식

웹 서버는 생성 요청을 `.local/codex-requests`에 저장한다. 같은 저장소의 Codex App 작업이 `$storyboard-workbench` 스킬로 요청을 읽어 현재 Codex 모델, 내장 `image_gen`, 설정된 macOS 음성을 사용하고 검증된 결과를 프로젝트 revision에 반영한다. `OPENAI_API_KEY`와 OpenAI SDK는 필요하지 않다.

## 현재 경계

- 지원 입력은 계약이 명시된 `native-v1`과 `production-v1`이다. 임의 문서 가져오기는 지원하지 않는다.
- 자동 검사는 문자열·시간·참조·상태 무결성을 판정한다. 그림의 연출, 반전 노출, 낭독 자연스러움은 사람이 승인한다.
- PRJ-007의 다른 대표 예외와 전체 32개 구간, 구조가 다른 실제 두 번째 작품은 후속 제작 검토 대상이다.
- 편집기 프로젝트 파일과 영상 생성 서비스 연결은 Plan의 후속 범위다.
