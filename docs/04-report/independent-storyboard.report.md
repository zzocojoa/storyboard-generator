# 독립 콘티 생성 — 검증 결과

같은 원본 패키지로 별도 콘티를 생성하고 목록에 추가해 바로 여는 기능을 제공한다. 계약은 [문서 패키지 Design](../02-design/features/document-handoff.design.md), 조작 방법은 [README](../../README.md)의 같은 패키지로 별도 콘티 시작을 따른다.

## 자동 검증

- `npm run check`: 타입 검사, 65개 파일의 1,232개 테스트, 필수 테스트 레지스트리, JSON Schema 정합성, 웹 빌드 통과.
- 전체 E2E 28개 중 27개가 첫 실행에서 통과했다. 기존 가져오기 테스트는 상태 안내가 두 개가 된 화면에서 선택자가 모호해 실패했다. 진행 상태 영역으로 선택자를 한정하고 해당 테스트를 다시 실행해 통과했다. 최종 검증 범위는 28개 모두다.
- 새 검증은 세 입력 어댑터의 원본 보존, 독립 편집·생성 요청, 동일 요청 재시도, 다른 입력의 충돌, Source Update, JSON 재읽기·PDF 출력, 저장소 재열기, 두 UI 진입 경로, 생성 후 목록·편집기 전환, 의도적인 추가 생성과 390px 화면을 포함한다.
- 최초 제한 환경의 전체 검사에서는 로컬 HTTP 서버 열기 권한으로 오디오 테스트 하나가 중단됐으며, 권한을 갖춘 재실행에서 위 전체 검사를 통과했다.

## 실제 사용 데이터

2026-09-10 실행 중인 4317 서버에 반영한 뒤, 사용자의 `draft-01/storyboard_handoff.json`을 새 콘티 생성 화면에서 가져왔다.

- 이름: **의부증의 늪 — draft-01**
- 작업 ID: `storyboard:7fe9debd-f4a0-4dae-9fdb-8b5db0c8e450`
- 원본 이야기 ID: `PRJ-007`, 12장면·32컷 초안, revision 0
- 입력 패키지의 30fps·48kHz·16:9와 인물 연결 8개를 보존했다. 미정 글자의 편집용 제안 유지 시간은 2,000ms다.
- 목록이 2개에서 3개가 됐고 새 콘티가 즉시 열렸다. 페이지 새로고침 뒤에도 목록에서 다시 열었다.
- 기존 PRJ-007 저장본·자산·버전과 생성 패키지의 26개 파일 해시를 전후 비교해 변경 0건을 확인했다.

실행 로그와 파일 대조 결과는 `.local/validation/independent-*`에 있다. 새 콘티는 편집용 초안이며 그림·음성 생성과 최종 출력 검토 완료를 의미하지 않는다. 기존 콘티의 자산·승인·편집 이력은 새 작업에 복사하지 않는다.
