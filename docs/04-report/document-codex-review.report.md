# 문서 연결·설정 Codex 검토 — Report

## 구현 결과

웹의 **Codex로 검토하고 채우기**가 설치된 Codex App 엔진으로 선택한 8개 문서를 검토하고 빈 연결·제작 설정을 입력한다. 현재 폼의 사용자 수정은 보존하고, 연결 추론·제작 추천·문서 확인·프리셋·사용자 지정을 구분한다. 추론·추천에는 실제 인용 근거와 확인 상태가 있으며, 확인 뒤 패키지 생성으로 진행한다. 제작 프리셋을 명시적으로 저장하고 다른 스토리에 선택해 적용할 수 있다.

범위는 [Plan](../01-plan/features/document-codex-review.plan.md), 구조는 [Design](../02-design/features/document-codex-review.design.md), 요구사항별 검사 경로는 [Check](../03-analysis/document-codex-review.analysis.md), 사용법은 [README](../../README.md#제작-문서-8개에서-패키지-만들기)를 따른다. bkit MCP 도구 상태 등록은 수행하지 않았다.

최초 Playwright 실행은 macOS의 브라우저 프로세스 실행 제한으로 시작하지 못했다. 필요한 실행 권한을 적용해 실제 브라우저 검사를 완료했다. 개발 중 발견된 종료 직후 재시도 경쟁, 시작 직후 취소, 프리셋의 접근 가능한 이름, 재검토 실패 후 이전 제안의 근거 표시 문제는 원인을 수정했다. 일반 테스트 timeout·retry 및 기존 CI 설정은 변경하지 않았다.

실제 PRJ-007에서는 강태균→CHAR-01, 박도현→CHAR-05를 추론으로 입력했다. 백기철·윤서진·오민주는 CHAR-02·03·04의 장면별 출연 조합이 같아 미정으로 남겼다. 30fps·48kHz·16:9는 문서의 확정 사실이 아닌 제작 추천으로 표시했다. 화면의 6개 제안은 확인 전 상태로 남겨 제작자가 근거를 검토할 수 있다. 원본 밖의 구조화 파일에서 정답을 가져오거나 나열 순서로 ID를 채우지 않았다.

초기 실험에서는 화면비를 해상도처럼 1920/1080으로 제안하는 표현을 발견했다. 프롬프트에서 기약 화면비를 요구하도록 명확히 했고, 최종 실제 브라우저 검토에서 16/9 입력과 추천 이유를 확인했다. 합성 스토리의 초기 실제 모델 결과는 구조·연결 검증 증거이며 최종 화면비 표현의 증거는 마지막 PRJ-007 실행이다.

## 지원 경계

현재 컴퓨터의 설치 엔진 경로는 서버 설정에 명시되어 있다. 다른 설치 위치·지원하지 않는 프로토콜·ChatGPT 미로그인 상태는 구체적인 오류로 표시하며 API 키나 다른 실행 파일로 자동 전환하지 않는다. 요청당 입력·응답은 각각 2MB, 동시 실행은 1개이며 현재 설정의 제한 시간은 240초다. 요청별 요금은 측정하지 않았다.

인용문이 원문에 존재한다는 검사만으로 추론의 의미상 정답을 증명하지 않는다. 미정 연결은 제작자가 확인하며, 이 기능은 문서 가져오기 입력의 검토·추천·보존을 완료한 것이다. 그림·음성 생성이나 전체 콘티 Final 승인을 완료한 것으로 간주하지 않는다. 합성 사례는 다른 실제 작품의 제작 품질 검증을 대신하지 않는다.

새 버전은 로컬 서버 `http://127.0.0.1:4317/`에서 확인할 수 있다. 구현·검증은 로컬 기능 브랜치 범위이며 원격 PR·CI·master 병합과 구별한다.
