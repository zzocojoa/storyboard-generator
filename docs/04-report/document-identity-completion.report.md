# 보충 인물 근거와 최종 연결 검증

검증일: 2026-09-10. 사용자가 승인한 범위인 보충 인물표 검증 → 연결 적용 → Codex App 재검토 → 근거를 포함한 패키지 저장·재읽기를 구현하고 실제 화면에서 완료했다. 실행 주소는 `http://127.0.0.1:4317/`이다.

## 구현 범위

연결·설정 화면의 **인물 대응표로 보완**에서 인물 원본과 제작 근거 파일을 직접 지정한다. 서버는 현재 8개 문서와 프로젝트, manifest→footprint→characters 해시 연결, 이름·ID의 유일성, 후보와 기존 입력의 충돌을 검사한다. 최종 인물 연결 표는 현재 이름–ID, 완료·미확정 제안·미연결·충돌을 구별한다. 가져올 인물 목록이 없는 경우에만 연결 대상 없음을 안내한다. 보충 파일을 지정하면 자동 연결 버튼으로 검증·재확인·적용을 연속 실행하며, 별도 미리보기 후 적용도 지원한다. 적용 직전에 파일과 입력 기준을 다시 확인하며, 빈 연결만 채우고 확인된 연결·제작 설정은 유지한다.

적용 후 Codex App이 8개 문서와 검증된 인물 대응을 다시 검토한다. 원본 대응은 코드가 검증한 `identity-document` 근거로 기록하며 모델의 추론과 구분한다. 미해결 사유와 보완 경로는 해당 입력 옆에 남긴다. 변경된 입력에 오래된 검토 결과를 덮지 않는다.

설정 계약 1.2.0은 보충 자료의 내용·해시와 필드별 연결 근거를 함께 저장한다. 패키지를 다른 위치에서 다시 읽을 때도 이 근거를 검증하며 외부 인물 원본 경로가 남아 있어야 할 필요는 없다. 기존 설정 계약은 유지한다. 지원 계약과 모듈 경계는 [설계](../02-design/features/document-codex-review.design.md)를 따른다.

## 실제 자료 실행 결과

- 실제 제작 문서의 미연결 인물 **3명 → 0명**: 윤서진 `CHAR-02`, 백기철 `CHAR-03`, 오민주 `CHAR-04`.
- Codex App 요청 `0302c1b1-f530-4521-9b6e-19260868e5fb`, 모델 `gpt-6-astra`, 상태 `completed`, 처리 시간 **22,128ms**. 다섯 인물 대응의 일치와 추가 연결 수정이 필요 없음을 확인했다.
- 새 패키지: [storyboard_handoff.json](../../.local/prj-007-identity-verified-20260910/storyboard_handoff.json), 버전 `identity-verified-20260910`.
- 저장 후 실제 패키지 읽기·가져오기 함수를 실행해 **12장면, 32구간, 원문 95개, 내레이션 12개, 패널 발화 16개**와 세 연결의 근거 보존을 확인했다.
- 원본 자료와 기존 프로젝트의 현재본·버전·자산 **37개 파일**을 전후 SHA-256으로 비교했다. 변경은 **0개**다. [실제 실행 기록](../../.local/validation/identity-live-summary.json)

현재 사용자 탭 `3`에서 이전 웹 빌드가 열려 있고, 재검토 입력의 보충 파일 경로가 비어 있는 상태를 확인했다. 이미 검증된 같은 문서를 다시 가져올 때 근거를 되찾지 못해 선택할 ID가 표시되지 않는 흐름을 보완했다. 완료된 검토에 저장된 인물 원본 사본을 현재 8개 문서·프로젝트·해시 사슬·후보·입력값과 다시 검증하여 **적용 전** `선택할 ID`와 자동 선택 버튼을 표시한다. 모델의 과거 추측을 재사용하지 않는다.

실제 서버를 갱신하고 같은 사용자 탭을 새 웹 빌드 `index-BbMpFS3i.js`로 다시 열었다. 기존 입력을 화면에서 복원한 뒤 124개 입력값을 비교해 차이가 없음을 확인했다. 복원한 인물 2명과 제작 설정 4개의 출처는 이번 화면에서 `사용자 지정`이며 이전 탭의 추론 감사 상태를 복원했다고 간주하지 않는다.

보충 파일 경로를 다시 입력하지 않은 상태에서 백기철 `선택할 ID: CHAR-03`, 윤서진 `선택할 ID: CHAR-02`, 오민주 `선택할 ID: CHAR-04`와 **확인된 3명 자동 선택** 버튼을 실제 DOM·접근성 트리에서 확인했다. 버튼 실행 후 **8/8명 연결 완료**, **연결 확인 필요 0개 · 제작 설정 입력 완료**이며 변경된 입력은 이 세 빈칸뿐이다. 실제 Codex 검토 `39f87a9d-b44a-4716-a3c6-28aec684cd32`는 `gpt-6-astra`로 **37,481ms** 후 완료됐고 추가 제안은 없었다. 현재 탭은 2단계의 최종 인물 연결 표를 보여 준다. 새 패키지는 생성하지 않았다.

현재 검증에는 자동 연결 도중 파일이 바뀌면 빈 연결을 보존하는 경우, 중복 ID·미확정 추론을 완료로 표시하지 않는 경우, 인물 목록의 정상 부재를 포함한다. 검증은 해시·프로젝트·현재 값 충돌, 중복·잘못된 후보, 파일 변경·symlink·외부 origin 거부, 보충 자료 해제 시 사용자 값 보존, 단계 이동·모바일 화면, 새 패키지 저장과 재읽기를 포함한다. 기존 추론으로 확인한 인물 2명과 추천 설정 4개를 보충 연결 적용 뒤에도 보존하는 E2E를 실행했다. 인물 배열 순서와 ID가 다른 독립 합성 자료도 같은 핵심 경로로 검증했다. 합성 검증을 다른 실제 작품의 제작 품질 검증으로 간주하지 않는다.

## 지원 경계

현재 보충 입력은 `production-characters-v1`과 `production-footprint` 1.0.0의 명시적 이름·ID 대응을 지원한다. 같은 문서의 검증된 저장 근거가 있으면 보충 파일 경로를 다시 입력하지 않아도 된다. 처음 가져오는 작품에 검증된 근거가 없고 8개 문서만으로 ID를 구별할 수 없다면 원본 대응표 또는 제작자가 아는 정확한 연결이 필요하다. 임의 상위 폴더 탐색이나 같은 출연 장면만으로 인물을 배정하지 않는다. 이 계약과 맞지 않는 다른 형식은 별도 어댑터가 필요하며, 원본의 연결 근거가 부족하면 이유를 표시하고 보류한다. 서버 재시작 후 저장 근거 재검증, 변경·다른 프로젝트·충돌 입력·손상된 저장 근거의 거부를 검사했다.

이번 완료 대상은 입력 패키지의 인물 연결이다. 기존 콘티의 그림·음성·Final Readiness는 별도 제작 단계이며, 기존 저장·자산 경고를 해결하거나 최종 콘티를 완성했다고 판정하지 않는다. 변경 사항은 현재 워킹 트리에 있으며 이번 작업에서 커밋·PR·머지를 실행하지 않았다.
