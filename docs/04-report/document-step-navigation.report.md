# 문서 패키지 단계 이동 검증

검증일: 2026-09-10. 범위는 문서 입력 화면의 완료 단계 재방문, 입력 유지, 변경 내용 재검증과 기존 패키지 보존이다. 동작 계약은 [문서 입력 설계](../02-design/features/document-handoff.design.md)를 따른다.

## 확인 결과

| 항목 | 결과 |
|---|---|
| 생성 전후 상단 단계 버튼으로 3→1→2→3 이동 | 입력 폴더, 연결, 제작 설정, 출력 폴더·버전, 임시 글자 유지 시간 보존 |
| 설정을 바꾼 후 3단계 재진입 | 필수 값과 연결을 재검증하고 오류가 있으면 해당 입력 화면에 유지 |
| 생성 후 설정·검토 근거 변경 | 기존 결과를 현재 입력의 결과로 불러오지 않고 새 폴더·버전 요구 |
| 수정된 패키지 생성·가져오기 | 이전 패키지 내용 보존, 새 버전과 변경된 프레임레이트가 저장 프로젝트까지 반영 |
| 원본 문서 변경·다른 이야기 선택 | 변경 감지, 연결 재검토, 다른 이야기의 설정·연결 초기화 |
| Codex 검토 중 단계 이동 | 이동 차단; 검토 완료 후 이동·재검증 가능 |
| 모바일·키보드 | 375px 폭의 가로 넘침 없음, 단계 버튼 Enter 이동 확인 |
| 실제 PRJ-007 화면 | 기존에 검증한 연결·설정으로 3→1→2→3 이동 확인, 실제 원본·기존 패키지 변경 없음 |

## 범위의 한계

입력 상태와 생성 이력은 현재 페이지 세션에서 유지한다. 브라우저 새로고침을 넘어서는 초안 저장은 포함하지 않는다. 실제 프로젝트의 최종 그림·음성·출력 승인이나 인물 연결 추론 로직의 확장은 이번 검증 범위가 아니다.
