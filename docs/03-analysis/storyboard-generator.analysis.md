# 범용 콘티 도구 — 구현 일치 분석

분석 기준은 [Plan](../01-plan/features/storyboard-generator.plan.md)의 첫 완성본 필수 요구사항 FR-01~FR-10과 [Design](../02-design/features/storyboard-generator.design.md)이다. FR-11과 FR-12는 계획에서 후속 범위로 분류했으므로 일치율 분모에서 제외한다.

## 결과

필수 요구사항 10개 중 10개가 코드·자동 검사·실행 흐름에 연결되어 코드 기준 일치율은 **100%**다. 실제 생성 품질은 자동 검사와 별개이며, 현재 PRJ-007 `SEG-008` 한 구간까지 사람이 확인했다.

|---|---|---|
| FR-01 입력 패키지 | 일치 | `native-v1`, `production-v1` 어댑터와 패키지 경로·버전·해시 검사, 서로 다른 두 fixture 및 PRJ-007 전체 가져오기 테스트 |

## 설계와 구현의 차이

- 설계에는 기본 컷 편집과 단일 프레임 흐름만 구체적으로 기술돼 있던 부분이 있었다. 구현은 시작·키·끝 프레임, 컷 전환, 연속성 전후 상태, 실패 목록까지 확장했고 Design을 현재 모델에 맞춰 갱신했다.
- 가이드 음성은 사용자가 확정한 Codex App 실행 방식에 맞춰 macOS `say`와 `afconvert`로 생성한다. 서버에서 API 키나 OpenAI SDK를 사용하지 않는다.
- 생성 비용은 외부 API 호출이 없어 API 비용으로 측정하지 않는다. 생성 대기 시간과 사용자가 수행한 재생성 횟수는 요청 기록으로 추적할 수 있지만 수동 제작 대비 생산성 수치는 아직 산정하지 않았다.

## 실행 검토

- 합성 범용 프로젝트에서 컷 제안, 이미지, 음성, 편집, 재생, 내보내기 흐름을 확인했다.
- PRJ-007 `SEG-008`에서 원문 5단위를 90초의 5개 컷으로 제안했다. 첫 프레임은 모호한 실루엣을 제거하도록 설명을 고쳐 재생성했고, 두 사람의 손·뒤집힌 사진·세 장의 문서만 보이는 결과를 승인했다.
- `UNIT-023` 발화는 Yuna 음성 WAV로 만들고 실제 5,600ms를 측정해 오디오 큐와 자산에 반영했다.
- 시각 문맥이 전혀 없는 프레임 요청은 `INSUFFICIENT_VISUAL_CONTEXT`로 실패했고, 영속 실패 상태와 웹 상태 메뉴에 원인·대상이 표시되는 것을 확인했다.

## 남은 제작 검토

코드 누락은 발견되지 않았다. 제품을 다른 형식으로 확장하기 전 다음 증거가 더 필요하다.

- Plan 9.3절의 패널, 메시지 비노출, J컷, 자막 최소 노출, 연속성, 마지막 무음 대표 구간 검토
- PRJ-007 전체 분량의 그림·낭독 호흡 및 추가 제작 자원 검토
- 구조가 다른 실제 두 번째 작품의 입력 어댑터 적합성 검토

이 항목들은 첫 완성본의 기능 구현과 분리된 제작 품질·지원 범위 검증이다.
