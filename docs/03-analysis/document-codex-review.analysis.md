| 요구사항 | 구현 근거 | 검증 경로 |
|---|---|---|
| 1. 버튼으로 실제 실행 | `review-engine.ts`의 ChatGPT 인증·stdio 협상, `review-service.ts`, 웹 검토 Hook | 실제 설치 엔진 실행, 자식 프로세스 프로토콜 시험, 브라우저 시작·진행·완료 |

검토 과정에서 종료 기록 게시 직후의 재시도가 이전 완료 요청을 재사용하던 경쟁을 고쳤다. 브라우저에서는 서버가 요청 ID를 반환하기 전 취소를 활성화하지 않으며, 재검토 실패 뒤에도 이전 제안과 근거를 확인할 수 있다. 테스트 한도나 재시도 횟수를 늘려 문제를 가리지 않았다.

문서 인용문이 존재한다는 검사는 의미상 연결의 정답을 증명하지 않는다. 따라서 모델 추론은 사용자 확인이 필요한 제안이며, 구분할 근거가 없는 ID를 자동 확정하지 않는다. 이 검토의 완료는 전체 콘티의 Final Ready 판정과 별개다.
